# NexusCorp B2B Systems

**NexusCorp** is an interactive web platform designed for B2B growth agencies, enterprise software consultancies, and lead generation experts.

## Features
- **ROI Calculator**: Interactive pipeline and revenue growth projection tool.
- **Diagnostic Funnel**: Multi-step qualification wizard assessing enterprise digital maturity.
- **Case Studies**: In-depth modals showing problem breakdowns and verified metric growth.
- **System Architecture**: Visual system flows showing Traffic -> Funnel -> CRM Webhooks -> Sales Follow-up.

## Tech Stack
- React 18
- Tailwind CSS
- Lucide Icons
